# Evidensprinciper

- Bind källan och resultatet till rätt version så att en granskare kan återfinna exakt det underlag som användes.
- Redovisa uppgiftsutfall, mätbarhet och upprepbarhet som olika besked.
- Visa kvarstående osäkerhet. Upprepbarhet förblir oavgjord när jämförelseunderlaget är för litet.
- Skilj på kontroll av sparade bytes och verifiering av ett påstående om en verklig aktivitet.
