# Vision

Vi vill göra det lättare att granska en AI-leverans med samma underlag som användes när arbetet utfördes. En granskare ska kunna se källan, förstå var en avvikelse uppstod och avgöra vad som behöver följas upp.

Vi börjar med avgränsade dokumentuppgifter där det går att beskriva uppgiften, visa ett tydligt källspann och komma överens om vad som räknas som godkänt.
