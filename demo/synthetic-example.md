# Exakt återgivning av ett textspann

Det här är ett sparat syntetiskt exempel. Uppgiften var att återge ett textspann exakt.

| Original | Rapporterat |
| --- | --- |
| `The **A** works` | `The A works` |

| Kontroll | Utfall | Skäl |
| --- | --- | --- |
| Uppgiften uppfylldes | Nej | Fyra asterisker saknas i det rapporterade spannet. |
| Resultatet gick att mäta | Ja | Det rapporterade spannet kunde kopplas till exakt ett motsvarande ställe i källan. |
| Upprepbarhet | Oavgjord | Provet hade noll jämförelsepar. |
